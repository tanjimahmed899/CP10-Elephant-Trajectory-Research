RMPG-U v2 FIXED — TRAINREAL VALIDATION EXPERIMENT
==================================================================================

IMPLEMENTATION FIX
- Prediction and auxiliary gate supervision now use gate_logits from the SAME forward pass.
- The previous second encoder/fusion/dropout pass has been removed.
- Architecture and hyperparameters are otherwise unchanged.

PROTOCOL
- Training: BIRDSAI TrainReal neural-training tracks only.
- Validation: fixed track-disjoint TrainReal validation.
- BIRDSAI TestReal NOT loaded.
- WildBox NOT loaded.
- Feature normalization: training samples only.
- Gate temperature: training targets only.
- Validation future is used only after checkpoint selection for gate diagnostic scoring.

ARCHITECTURE
- GRU temporal encoder
- explicit history-only motion features
- stationary/CV physical-prior gate
- nonlinear residual trajectory branch
- heteroscedastic Gaussian uncertainty head
