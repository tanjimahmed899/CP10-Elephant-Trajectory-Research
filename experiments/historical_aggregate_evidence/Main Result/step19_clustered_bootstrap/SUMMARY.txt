METHOD
- Bootstrap replicates: 2000
- Random seed: 20261017
- Primary bootstrap cluster: trajectory track.
- Resampling is stratified within source_group.
- All overlapping windows belonging to a sampled track remain together as one resampled cluster.
- 95% percentile bootstrap confidence intervals.
- Source-level uncertainty is NOT presented as a bootstrap CI because only 3 fresh WildBox sources and 5-6 TestReal sources are available.
- Source robustness is instead summarized using leave-one-source-out sensitivity.
- No model retraining, model selection, warning threshold tuning, or protocol modification occurred.

INTERPRETATION
- BIRDSAI TestReal remains a frozen in-domain benchmark previously inspected during development.
- Fresh WildBox remains the preregistered unseen source-video external holdout.
- Forecasting errors are normalized image-plane coordinate errors, not metres.
- Virtual-geofence events are experimental image-plane boundary crossings, not actual human-elephant conflict events.
- Horizon and domain contrasts are descriptive independent clustered-bootstrap contrasts, not paired hypothesis tests.
