STEP 18 — VIRTUAL-GEOFENCE EARLY-WARNING PROTOCOL
==================================================================================

STATUS
- Protocol frozen before TestReal / fresh WildBox geofence evaluation.
- No downstream classifier is trained.
- No warning threshold is optimized using F1, AUROC, AUPRC or test performance.
- Warning threshold = 0 signed normalized-coordinate units, corresponding to predicted boundary crossing.
- Step18A uses only fixed TrainReal track-disjoint validation for diagnostic evaluation.
- BIRDSAI TestReal is not loaded in Step18A.
- WildBox is not loaded in Step18A.

MODEL
- Frozen Compact Temporal Transformer.
- Frozen seeds: 42, 52, 62.
- Forecast = arithmetic mean of the three seed trajectories.

VIRTUAL GEOFENCES
- Axes: x and y.
- Fixed normalized boundaries: 0.25, 0.50, 0.75.
- For each axis-boundary pair, the last observed position determines the current safe side.
- The opposite side is treated as the virtual risk zone.
- Therefore each trajectory normally produces six eligible directional boundary instances.
- These are experimental virtual boundaries; they are NOT labeled crop/village conflict zones.

EVENT DEFINITION
- True crossing: ground-truth future reaches/crosses the boundary into the risk side.
- Predicted warning: ensemble-mean future reaches/crosses the same boundary.
- Continuous risk score: maximum directional signed boundary penetration.
- Decision threshold: risk_score >= 0.
- TTE: first future crossing timestep.
- Warning lead time for a true positive is actual TTE because the warning is generated at forecast time zero.

METRICS
- Precision, recall, F1.
- False-warning rate and miss rate.
- AUROC and AUPRC using continuous risk score.
- TTE MAE and TTE bias among correctly warned crossings.
- Warning lead time.
- Boundary-level and source-level metrics.
- Seed vote/disagreement retained as diagnostic information only.

LIMITATION
- Geofence positives are rare and source-concentrated.
- This experiment is a secondary downstream early-warning benchmark, not evidence of actual human-elephant conflict prediction.
- Coordinates are normalized image-plane units, not metres.
- Seed vote fraction is not interpreted as a calibrated probability.
