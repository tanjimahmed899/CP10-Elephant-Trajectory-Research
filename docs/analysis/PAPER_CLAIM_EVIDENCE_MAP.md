## Required files for a defensible experimental claim

1. **Exact experimental protocol:** dataset/source IDs and split, input/output shape, exclusion rules, model architecture, training seed, fixed hyperparameters and software environment.
2. **Execution evidence:** original script revision, command invocation, run log and checkpoint SHA-256 (checkpoint itself only when license/storage permit).
3. **Numerical evidence:** prediction and GT arrays or an approved reproducible aggregate, per-sample/per-source CSV, metric computation code and run-specific summary.
4. **Visual and reporting evidence:** one versioned plot with caption, interpretation and limitations.
5. **Traceability:** connect manuscript table/figure IDs to filenames and hashes in a source manifest. Mark missing artifacts honestly.

**Privacy/license rule:** Never automatically publish provider videos, detailed camera pose/location data, dataset annotations, COCO images or model weights just because files are present. Use original dataset access URLs and local SHA-256 manifests. Maintain a separate controlled-access copy if permitted.
