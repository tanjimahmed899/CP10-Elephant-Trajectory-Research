# WildLive: representative aerial elephant annotation figures

Six SHA-256-verified research visualizations from the WildLive dataset, included as limited representative **third-party-source annotation visualizations** (not a redistributed original image/frame archive). These figures support qualitative annotation QA, scene overlap discussion, and dataset diversity; **they do not demonstrate trained detector output, tracking performance, trajectory forecast accuracy, or independent capture groups.**

| File | Dataset portion | Evidence scope |
|---|---|---|
| `WL_Fig01_DJI0161_single_elephant_temporal.jpg` | DJI_0161_video1, five sampled frame indices | Sampled annotations of ID 0, not automated ID persistence |
| `WL_Fig02_DJI0204_six_elephants_zoom.jpg` | DJI_0204_video1, frames 0/100/200 | Multiple annotated elephant IDs and crowded group |
| `WL_Fig03_DJI0204_full_frame_context.jpg` | DJI_0204_video1 | Full-frame scale and visualization context |
| `WL_Fig04_DJI0204_video1_video2_scene_comparison.jpg` | DJI_0204_video1 and video2 | Scene similarity; do not treat videos as independent capture groups |
| `WL_Fig05_DJI0207_full_frame_temporal.jpg` | DJI_0207 | Sampled frame 0/200/400/600/867 annotations |
| `WL_Fig06_DJI0207_three_elephants_zoom.jpg` | DJI_0207 | Close-formation annotations and overlapping boxes |

See [`FIGURE_SOURCE_SHA256.csv`](FIGURE_SOURCE_SHA256.csv) for source-filename traceability, checksums and captions, and [`ATTRIBUTION_AND_REUSE.md`](ATTRIBUTION_AND_REUSE.md) for copyright and non-commercial licensing conditions. WildLive *frame indices* are not verified seconds; annotation overlays are not detector/tracker predictions.

For maximum reproducibility, download the original WildLive source dataset only from the [official University of Bristol catalogue](https://data.bristol.ac.uk/data/dataset/ewnuoroebuae20vei0cu6zu69), subject to its licence and access conditions.
