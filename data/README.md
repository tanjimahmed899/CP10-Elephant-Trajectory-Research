# Dataset inventory (data not redistributed)

- **Elephant RGB detection dataset:** 3,280 annotated images / 4,477 instances, split 2,295/656/329 in historical report; check source and rights before download.
- **BIRDSAI TrainReal/TestReal:** aerial thermal recordings and annotation tracks; primary in-domain benchmark and domain-adaptation development. The recorded TestReal sequence cohort was repeatedly evaluated; it is not newly untouched.
- **WildBox:** source drone-recorded RGB with camera metadata; use the official source/license. Fresh, EXP3 and Stage 5 are distinct video sets but share recording groups.
- **BAMBI Flight 6:** red-deer/human cross-species stress test, NOT elephant confirmation.
- **COCO:** selected mixed-species negative-image detector stress examples only; distribution rights separate.

Store local source videos, GPS, extrinsics and potentially sensitive wildlife locations outside the Git repository. Keep dataset checksums/manifests in a controlled location.
