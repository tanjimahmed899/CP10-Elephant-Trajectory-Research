# Source code and data distribution status

**Repository visibility:** Public research evidence repository (visibility decided by the repository owner).

**Code licensing:** No general open-source license has been selected or granted. Public GitHub access does not, by itself, confer permission to reuse or redistribute the project's original code. The repository owner may select a license later after confirming authorship and university/co-author policies.

**Third-party material:** BIRDSAI, WildBox, BAMBI, COCO, Ultralytics and other tools/data retain their own terms. Check upstream licenses and acknowledgement requirements before redistributing data, models or adapted code.

**Restrictions and publication safety:** Do not add authentication tokens, private video recordings, confidential data, precise wildlife location information, identifiable third-party individuals or restricted checkpoints. Where appropriate, publish an approved aggregate and cryptographic hash rather than the original asset.

**Research status:** Retrospective experiments and conditionally GT-filtered forecasting analyses are not proof of a validated operational geofence or deployment-ready wildlife protection system.
